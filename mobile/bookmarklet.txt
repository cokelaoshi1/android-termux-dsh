# 手机端适配 — 书签小工具 (bookmarklet)
# 用法：
#   1) 手机浏览器（任意，无需装扩展）新建书签，名字随意（如 "dsh 移动版"）
#   2) 把下面这一整行 javascript: 代码粘贴到书签的「网址」栏
#   3) 打开 dsh web (http://127.0.0.1:3080) 后，点这个书签即注入移动端样式
# 提示：每次刷新页面需要重新点一次；想自动注入请用 dsh-mobile.user.js（需 Tampermonkey/Violentmonkey，Kiwi 浏览器可装）
